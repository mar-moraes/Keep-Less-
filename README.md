# Keep Less

A Google Keep clone built with React.

## Features

-   **Create Notes**: Add title and content.
-   **Edit Notes**: Click on a note to edit it.
-   **Organization**:
    -   Archive notes.
    -   Delete notes (move to Trash).
    -   Restore from Trash.
    -   Permanently delete.
-   **Color Coding**: Change the background color of your notes.
-   **Navigation**: Sidebar to switch between Notes, Archive, and Trash views.
-   **Premium Aesthetics**: Glassmorphism and Material Design inspired UI.

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
